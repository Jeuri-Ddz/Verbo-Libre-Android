RESUMEN ACTUALIZADO DEL PROYECTO: VERBO LIBRE (Android)
Fecha: 2026-08-26
----------------------------------------------------------------------

1. SISTEMA DE CONTENIDO DIARIO (NUEVO)
--------------------------------------
- IMPLEMENTACIÓN 'MAZO BARAJADO' (Shuffled Deck):
  * Se implementó un sistema determinista basado en ciclos para versículos y devocionales.
  * Lógica: Se calcula la fecha de inicio del usuario, los días transcurridos y se baraja la lista usando una semilla fija por ciclo.
  * Resultados: Cero repeticiones de contenido hasta completar la lista. Al terminar un ciclo, se re-baraja automáticamente con una nueva semilla derivada.
  * Fondos: Los índices de fondo (1-5 para versículos, 6-10 para devocionales) ahora también son deterministas y consistentes durante el día.

2. LIMPIEZA DE CÓDIGO Y DEBUG
-----------------------------
- ELIMINACIÓN DE 'DebugConfig':
  * Se borró la infraestructura de forzado manual de IDs.
  * Se eliminaron las funciones de 'Preview' (toque en título) para evitar cambios accidentales por el usuario.
- OPTIMIZACIÓN DE IMPORTACIÓN:
  * El 'DataImportManager' ahora verifica si las tablas están vacías antes de proceder con la carga de JSONs, evitando I/O innecesario en cada arranque.
  * Se eliminaron archivos JSON residuales (`gpt.json`, `new.json`).

3. HISTORIAL DE LECTURA Y PROGRESO
----------------------------------
- IMPLEMENTACIÓN 'lastReadChapter':
  * El botón "Continuar lectura" en 'ChapterSelectionDialog' permite saltar al siguiente capítulo pendiente con un toque.
- COLORES DE PROGRESO:
  * 0% / Parcial: Navy Accent (#33506E).
  * 100% (Completado): Verde Éxito (#3C9D6B).

2. CUALQUIER OTRO CAMBIO NO SOLICITADO EXPLÍCITAMENTE
------------------------------------------------------
- MIGRACIÓN INTEGRAL A HILT:
  * Se migró toda la Inyección de Dependencias a Dagger Hilt (v2.60.1).
  * Motivo: Eliminar el código repetitivo de factorías manuales y centralizar la gestión de bases de datos y repositorios.
- ACTUALIZACIÓN DE JAVA Y SDK:
  * El proyecto se subió a Java 17 y compileSdk 37. Se habilitó 'coreLibraryDesugaring' para soportar APIs modernas de fecha en dispositivos antiguos.
- REFACTORIZACIÓN DE AUDIO (TTS):
  * 'SpeechManager' ahora es un Singleton inyectado por Hilt. Se eliminó el paso del contexto de la actividad al ViewModel para prevenir fugas de memoria (Memory Leaks).
- OPTIMIZACIÓN DE RENDIMIENTO EN READER SCREEN:
  * Se implementó un sistema de "Geometría Pre-calculada" para los marcadores y notas en el 'Canvas'. Esto eliminó el lag de scroll que ocurría al tener muchos versículos marcados.
- REDISEÑO DE TOPAPPBAR (READER):
  * Se eliminó el botón de "Back" (flecha derecha) para ganar espacio.
  * Se centró el título (Libro + Cap) y se ancló el selector de versión (RVA/VBL) justo al lado del nombre del libro.
  * Se corrigió el posicionamiento del popup de traducción para que aparezca centrado sobre su botón.

4. ARQUITECTURA Y RENDIMIENTO
------------------------------
- INYECCIÓN DE DEPENDENCIAS:
  * Migración completa a Dagger Hilt.
- ACTUALIZACIÓN DE SDK:
  * Proyecto en Java 17 y compileSdk 37.
- OPTIMIZACIÓN DE RENDIMIENTO:
  * 'SpeechManager' Singleton inyectado por Hilt.
  * 'ReaderScreen' utiliza geometrías pre-calculadas para evitar lag de scroll.
- NAVEGACIÓN SEGURA:
  * Implementación de 'safeNavigate' para evitar doble navegación y crashes por toques rápidos.

4. BASE DE DATOS
----------------
- TABLA 'reading_progress' [NUEVA]:
  * id (PK), bookId, chapter, isRead (Int/Bool), readAt (Long).
  * Posee un índice único por (bookId, chapter) para evitar duplicados.
- TABLAS 'notes', 'bookmarks', 'verses':
  * NO han sufrido cambios en su esquema. Sus datos son compatibles con las versiones anteriores.
